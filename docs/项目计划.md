# 菜品识别与热量区间估算项目计划

选题：课程第02题，中等难度。建议论文标题：*Lightweight Food Recognition through Transfer Learning with Portion-Based Calorie Estimation*。

## 固定范围

- Food-101选10类，共约1万张已标注图片。
- MobileNetV3-Small，224×224输入；只训练分类头，再比较解冻末层。
- 照片给出类别，份量由用户输入，热量来自可追溯营养记录。
- 本机网页展示图片、Top-3、份量和估算区间。未完成训练时禁用照片分类。

## 实验安排

| 条件 | 骨干 | 颜色增强 | 目的 |
|---|---|---|---|
| A | 全部冻结 | 无 | 分类头基线 |
| B | 解冻最后一个特征块 | 无 | 与A比较微调范围 |
| C | 解冻最后一个特征块 | 有 | 与B比较增强 |

类别、输入尺寸、划分、种子、batch、学习率方案和训练预算保持可追溯。默认12轮上限、validation早停；按实际训练曲线和验证选择模型，不读test选超参数。初始种子42，正式汇总再以43、44复跑并报告均值、波动及配置。

报告Accuracy、Macro-F1、每类Recall、混淆矩阵、Params、注明输入尺寸与计数规则的MACs/FLOPs、真实推理耗时。热量估算验证单位、份量缩放与来源，不将营养查表的数值当作图像模型精度。

## 数据治理

原始数据在`data/raw/`，派生清单在`data/processed/`。保留Food-101官方test，仅从官方train派生val。按图片SHA成组，跨官方test的完全重复训练图排除并记录，其他同图组不拆分。

Food-101包含西式菜品；真实中式食堂可能存在明显域差异。后续食堂实拍单列验证，须获得拍摄与使用同意；不凭公开集成绩声称食堂场景同样准确。
